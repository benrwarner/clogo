# Category starting points

Starting points, not rules. **Always prefer the project's existing colours/fonts** if it has
them. Shift hues to avoid looking like the category leader. All fonts are on Google Fonts
(SIL OFL / Apache — free for logos) and work with `text-to-path.mjs --font "<name>"`.

## Picking colours well
- Darken the ink toward the primary's hue (coffee ink is brown-black, not `#000`).
- For dark mode, lighten the primary ~10–15% and use an off-white ink (`#f5f5f4`-ish).
- Keep the primary ≥3:1 contrast on white for the mark to read; if the brand colour is pale
  (yellow, mint), let the ink carry the wordmark and use the pale colour as accent/tile.
